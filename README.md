# TT Clip

**Keep context close.**

TT Clip is a local-first clipboard history app for macOS. It helps you keep text, code, links, images, and files close to the task at hand—then search, preview, copy, paste, or drag them into the next app when you need them.

**中文名称：贴贴剪切板。** This is the unified public home for the product previously introduced as TieTie.

> **Public beta hub**
>
> This repository is the public home for releases, product updates, and beta feedback. The TT Clip application source is intentionally not published here.

## Why TT Clip

- **Retrieve from the edge** — bring back useful context without leaving the app you are working in.
- **Work with real content** — preview images, long text, links, files, code, and LaTeX instead of hunting through anonymous clipboard rows.
- **Move between apps** — drag supported history items into another macOS app, or bring files into TT Clip from Finder.
- **Stay local-first** — your clipboard remains on your Mac unless you explicitly copy, export, drag, or share it.

## Privacy note

Please do **not** submit clipboard contents, private file paths, credentials, account data, or unredacted screenshots in a public issue. A neutral reproduction and a redacted diagnostic report are enough.

# Installation and permissions

## Public beta availability

TT Clip will publish a DMG here only after it has completed Developer ID signing and macOS notarization. Until a release appears on the [Releases page](https://github.com/teeoz/tt-clip/releases), there is no public installer to download.

## When the signed beta is available

1. Download the current `.dmg` from GitHub Releases.
2. Open the DMG and drag the app into **Applications**.
3. Open TT Clip from **Applications** and follow the in-app onboarding.

## Permissions

TT Clip explains each permission in context. Most clipboard history features work without cross-app automation permissions.

- **Accessibility** may be needed for an explicit paste or other cross-app control.
- **Input Monitoring** is only needed for the optional double-click-to-paste workflow.
- TT Clip checks whether a requested permission is actually active and points you back to **Settings → Privacy & Permissions** when it is not.

Never upload clipboard content, passwords, private paths, or unredacted diagnostic information when asking for help.

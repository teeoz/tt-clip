# 安装与权限指引

## 公开 Beta 状态

贴贴剪切板只会在完成 Developer ID 签名和 macOS 公证后，将 DMG 发布到 [Releases](https://github.com/teeoz/tt-clip/releases)。在 Releases 页面出现版本前，没有可供公开下载安装的正式 Beta。

## 正式 Beta 上线后

1. 从 GitHub Releases 下载最新 `.dmg`。
2. 打开 DMG，将应用拖入“应用程序”文件夹。
3. 从“应用程序”打开贴贴剪切板，按照应用内引导完成首次设置。

## 权限说明

贴贴会在功能确实需要时说明并请求权限。大多数历史记录功能不依赖跨应用自动化权限。

- **辅助功能**：仅在明确的跨应用粘贴或控制操作中可能需要。
- **输入监控**：仅在可选的“在输入框双击后粘贴”工作流中需要。
- 若权限在系统中已开启但尚未真正生效，可返回“**设置 → 隐私与权限**”重新检测。

反馈问题时，不要上传剪贴板正文、密码、私人路径或未脱敏诊断信息。
